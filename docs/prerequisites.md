# Prerequisites

Repository 14 is the integration stage: every project assumes knowledge from earlier repositories and names it in its
README's **Course context** section. Nothing here imports code from another repository — where a project needs a
shared helper (the ShopUNow `helpers` factory, the deep-agent skills, a sample corpus) a copy ships inside it, listed in
[data-sources.md](data-sources.md).

## General

- Python 3.11/3.12, virtual environments, `.env` files and chat-completion APIs.
- Git, Docker and Docker Compose; Node.js 18+ and npm for the React/Angular/Vite front ends.
- For the deployment projects: an AWS, Databricks or Pipecat Cloud account if you choose to deploy (optional —
  every project also runs locally).
